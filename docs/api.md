# API

[Back to README](../README.md)

All procedures live under `task` and are served at `/api/trpc`.

| Procedure     | Type     | Input                                         | Returns                 | Errors                     |
| ------------- | -------- | --------------------------------------------- | ----------------------- | -------------------------- |
| `task.list`   | query    | `{ limit: 1–50, cursor?: { createdAt, id } }` | `{ items, nextCursor }` | `BAD_REQUEST`              |
| `task.byId`   | query    | `{ id: uuid }`                                | `Task`                  | `BAD_REQUEST`, `NOT_FOUND` |
| `task.create` | mutation | `{ title, description? }`                     | `Task`                  | `BAD_REQUEST`              |
| `task.update` | mutation | `{ id, title, description? }`                 | `Task`                  | `BAD_REQUEST`, `NOT_FOUND` |
| `task.delete` | mutation | `{ id: uuid }`                                | nothing                 | `BAD_REQUEST`, `NOT_FOUND` |

## Validation and errors

`title` is required, trimmed and at most 120 characters; `description` is optional and at most 1000. Errors carry a semantic code, a readable message and, for validation failures, the errors per field:

```bash
curl -X POST localhost:3000/api/trpc/task.create \
  -H 'content-type: application/json' -d '{"json":{"title":""}}'
# 400 → message "Title is required", data.zodError.fieldErrors.title
```

Internal errors are logged on the server and reach the client as a generic message in production.

## Field mapping

The challenge names the fields in Portuguese; the code uses English names.

| Challenge     | Code          | Notes                                                                       |
| ------------- | ------------- | --------------------------------------------------------------------------- |
| `id`          | `id`          | UUID generated by the server                                                |
| `titulo`      | `title`       | Required, trimmed, 1–120 characters                                         |
| `descricao`   | `description` | Optional, up to 1000 characters; an empty value is stored as no description |
| `dataCriacao` | `createdAt`   | Set by the server                                                           |
| (added)       | `updatedAt`   | Set on every update; the card shows "Edited"                                |
